# TicketGURU
#### Video Demo:  <https://youtu.be/54R8JdxQxes>
#### Description:
TicketGURU is an online platform designed to simplify the process of booking tickets for museums and heritage sites. The website offers a clean and intuitive interface where users can browse different museums, view available tickets, and make bookings with ease. Built using modern web technologies, TicketGURU ensures a seamless user experience for both first-time visitors and regular users.

### Key Features:
- **Responsive Design:** The website is fully responsive, providing a smooth experience across devices including mobile phones, tablets, and desktops.
- **Browse and Search Museums:** Users can browse a wide variety of museums and heritage sites, search for their desired locations, and view essential information such as timings, ticket prices, and upcoming exhibitions.
- **Ticket Booking:** The platform allows users to easily select dates and book tickets in a streamlined checkout process.
- **User Accounts:** Registered users can sign in, view their booking history, and manage upcoming visits.
- **Secure Payments:** The website is integrated with secure payment gateways to ensure user data is protected while completing transactions.

### File Overview:
- **App.js:** The main entry point of the application that handles routing and renders different pages such as the homepage, museum listings, and booking pages.
- **components/Header.js:** Contains the navigation bar for the website, ensuring smooth navigation between different sections of the site.
- **components/MuseumList.js:** Displays a list of available museums, including search functionality to filter through museums based on user preferences.
- **components/BookingForm.js:** A detailed form that allows users to input ticket preferences (e.g., date, number of visitors) and complete the booking process.
- **components/Footer.js:** Provides website-wide information, links to support, and social media channels.
- **backend/routes/bookings.js:** Manages all booking-related requests on the server, including ticket availability and user reservations.
- **backend/models/Booking.js:** Defines the schema for storing booking information in the database, such as user details, museum booked, date, and payment status.

### Design Choices:
- **MERN Stack:** The website is built using the MERN stack (MongoDB, Express.js, React.js, and Node.js) for its efficiency in handling both front-end and back-end tasks, ensuring a fast and responsive user experience.
- **User-Friendly UI:** A priority was given to creating a simple and intuitive interface to make the ticket booking process easy for users of all ages.
- **Scalable Database Design:** The backend database is structured to handle a large number of bookings and user data, with the potential to scale as the platform grows.
- **Responsive Layout:** The layout adapts to different screen sizes, ensuring accessibility for users on both desktop and mobile devices.

### Challenges and Design Considerations:
- **Payment Integration:** The choice of payment gateway required balancing ease of use for users and security considerations to protect sensitive data.
- **Booking Workflow:** Special care was taken to streamline the booking process while ensuring users can easily correct errors, choose different ticket types, and confirm their purchases with minimal hassle.
- **Scalability:** The database and backend were designed to handle increasing numbers of users and bookings as more museums and heritage sites are added to the platform.

TicketGURU is designed to offer a seamless and efficient ticket booking experience for museum-goers, making it easy to discover and visit heritage sites with just a few clicks. With a focus on simplicity and user experience, the website serves as a central hub for cultural exploration.
